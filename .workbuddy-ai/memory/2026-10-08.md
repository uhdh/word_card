### 내가 정한 규칙 (전부 `scripts/MergeRules.gd` 한 파일)

7×7 = **바깥 링 24칸 = 경로**((0,0) 스폰 → … → **(1,0) 기지**), **안쪽 5×5 = 슬롯**.
뽑기 `20+5n`(**3번째마다 모음 확정**) · 병합 **같은 자모·같은 등급 3장 → +1등급**(자동) · 강화 등급×40 · 조합 30(상대 1장) · 판매 등급×15 · 타워 사거리 3.4칸·0.75초·피해 = 사전피해×(1+0.45×(평균등급−1)) · 웨이브 적 `4+n`·HP `24×1.19^(n−1)`·**5라운드 보스** · 시작 골드 120·HP 50.
**단어 판정** = 안쪽 가로 5줄 + 세로 5열을 한 줄씩 `HangulStreamParser` 로 파싱 → 그 줄이 곧 단어 타워. 사전에 없으면 `미지의 활자`로도 타워가 선다(운 나쁜 판이 아무것도 못 하는 것 방지).

### ⚠️ 밟은 함정 (README 에 12개로 정리)

1. **`trait` 는 예약어**(Godot 4.4+ GDScript trait). `var trait := …` → `Parse Error: Expected variable name after "var"` 로 **스크립트가 통째로 안 뜬다**. `MergeGame._fire()`·`MergePalette.trait_color()` 둘 다 걸렸다 → `tr`·`trait_id` 로 개명. (딕셔너리 **키** `"trait"` 는 문자열이라 안전.)
2. **`:=` 로 Variant 추론 = 오류**(`inference_on_variant` 기본 심각도가 `error`) — `var sel := dict.get(k,{})` 가 `Parse Error`. 타입 명시.
3. **줄바꿈 Label 이 최소 높이 928px 로 폭발**(폭이 정해지기 전 글자마다 접힘) → 화면이 **세로로 136px 넘침**. 반대로 줄바꿈을 끄면 긴 안내문이 **최소 폭 800px** 을 요구해 **가로로 넘쳐 4번째 버튼이 사라졌다**(`min.x 878`). → **긴 문구는 짧은 줄 둘로 나눠 쌓는다.**
4. **단어 라벨을 타일보다 먼저 그리면 위 칸 타일이 덮는다** → 맨 아랫줄 '나무' 라벨이 반쯤 가려졌다. `_draw_tower_labels()` 로 **타일 뒤에** 그린다.
5. **사거리 원이 보드 밖으로 나간다** — `draw_arc` 통짜로는 시안 고리 바깥까지 그려져 "보드가 잘린 것처럼" 보인다 → 원을 128조각으로 나눠 보드 rect 안 조각만 잇는다.
6. **스크린샷 시드에 같은 자모·같은 등급 3장을 깔면 자동 병합이 단어를 부순다** — `ㅏ` 5장 때문에 '사자'·'바다' 가 '사'·'다' 로 굳었다. 반복 자모는 등급을 달리한다.
7. **`matched` 는 "사전 단어인가" 가 아니라 "뜻에서 온 형태인가"** — 사전에 있어도 분류 폴백으로 떨어지는 단어가 많다. UI 에 `(사전 N)` 이라 썼다가 거짓말이 되어 `(뜻 반영 N)` 으로 고쳤다.
8. **`_wave_total` 을 `maxi` 누적하면 리셋 뒤에도 지난 판 최대치가 남는다**(7라운드 → 리셋 → 1라운드 진행 바 5/11). 라운드가 바뀔 때 다시 센다.
