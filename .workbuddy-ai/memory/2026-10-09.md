## 후속2 — "실행이 안되" (감독 지적) → **`.lnk` 를 바이트로 조립**

**증상.** 바로가기를 더블클릭해도 **아무 일이 없다.**

**결정적 진단 (대조 실험).** `ShellExecuteW` 반환값으로 갈랐다(>32 = 셸이 열었다):

| 대상 | 반환 |
|---|---|
| 없는 파일 | 2 |
| 있는 폴더 | 42 |
| `notepad.exe` | 42 |
| `WinGet\Links\godot.exe` | 42 |
| **기존 정상 `.lnk`(`볼링 코치.lnk`)** | **42** |
| **우리 `.lnk`** | **5 (액세스 거부)** |

→ **샌드박스 문제가 아니라 `.lnk` 자체가 깨졌다.** 필드 대조로는 절대 못 잡는다 — 타깃·인자·작업폴더·아이콘이 **전부 정상으로 읽힌다**.

**근본 원인 — `pylnk3` 의 writer 는 셸과 어긋난다.**
- `for_file()` 로 새로 만든 것 → **5**
- **정상 `.lnk` 를 파싱해 *그대로 되쓰기만* 한 것 → 5** (1063 → 2004 B 로 부푼다)
- 변형 A(`for_file` 만)=839 B / B(+LinkInfo)=947 B / C·D=1047 B — **A~D 전부 5**, 정상 기준은 42.
→ 즉 `pylnk3` 는 **파서지 생성기가 아니다.** IDList 재직렬화가 셸 규격과 어긋난다.

**고침 — 바이트 이식.** `.lnk` 는 `[헤더 76B][IDList][LinkInfo][StringData][ExtraData]` 이고, **IDList·LinkInfo 는 타깃만 가리킨다** → 타깃이 같으면 **Windows 가 만든 바이트를 그대로 물려받아도 된다.** 바꿀 건 `StringData` 뿐(이름·상대경로·작업폴더·인자·아이콘). 타깃이 같은 `.lnk` 를 자동 탐색하고(바탕화면·시작 메뉴), 없으면 **번들 픽스처**(804 B hex)로 떨어진다. 템플릿의 `LinkFlags` 중 **우리가 안 쓰는 비트는 지운다**(`0x4000 HasExpIcon` — 블록을 안 넣으므로).

**결과.** `ShellExecuteW -> 42` · `VERIFY fails=0` · 그리고 **실제로 게임 프로세스가 떴다**(`Godot_v4.7.2-stable_win64.exe` 12초 이상 생존).

**⚠️ 새로 밟은 함정 (다음에 또 만난다)**
1. **필드가 다 맞아도 셸이 거절할 수 있다** — 검증은 **`ShellExecuteW` 로 실제로 열어 봐야** 끝난다. 정상 `.lnk` 와 나란히 돌려 대조하면 확실하다.
2. **`LinkInfo.LocalBasePath` 는 시스템 ANSI** 다(UTF-16 아님) — `path.encode('utf-16-le') in prefix` 로 검사하면 **항상 거짓**이 나온다.
3. **IDList 개수 공식은 틀렸다** — 위 1차 기록의 "루트1+드라이브1+경로조각8 = 10" 은 **오류**다. 실측 **7** 이다. 개수로 계약을 세우지 말고 **템플릿 바이트를 그대로 물려받아** 비교하라.
4. **`os.replace` 로 쓰면 바탕화면 아이콘 자리가 초기화된다**(파일 신원이 바뀐다) — 실측 `(672,5) → (224,1633)`. **제자리 `open(path,"wb")`** 를 쓰고, 내용이 같으면 **아예 안 쓴다**.
5. **`LVM_SETITEMPOSITION` 은 *보이는 자리*만 바꾼다** — `SHChangeNotify(SHCNE_UPDATEDIR, SHCNF_PATHW, 바탕화면)` 로 **셸백에 기록**해야 새로고침·덮어쓰기 뒤에도 남는다(실측: 알림 없이는 되돌아갔다).
6. **`WinGet\Links\godot.exe` 는 심볼릭 링크다** — 실행하면 프로세스 이미지 이름이 **타깃 이름**(`Godot_v4.7.2-stable_win64.exe`)이 된다. `godot.exe` 로 찾으면 **못 찾는다**(거짓 음성). **전체 프로세스 목록 diff** 로 찾아라.
7. **`tasklist` 는 OEM 코드페이지**(여기선 cp949)로 뱉는다 — `subprocess.run(..., text=True)` 로 utf-8 디코드하면 `UnicodeDecodeError` 로 **터진다**.
8. **`shutil.which("godot")` 는 `PATHEXT` 로 `godot.EXE`(대문자)를 준다** — 템플릿 `LinkInfo` 에는 `godot.exe`(소문자)가 박혀 있어 **문자열 비교가 어긋난다**(정상이 빨개진다). 경로 비교는 **`normcase`**.
9. **PowerShell 로도 COM 은 못 쓴다** — `New-Object -ComObject WScript.Shell` 이 툴 단에서 **차단**된다(`COM object instantiation can run arbitrary code`). 툴 출력도 안 돌려준다.
